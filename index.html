核心套路

甘油三酯-葡萄糖(TyG)指数作为胰岛素抵抗替代指标，结合TyG-BMI、TyG-WC、TyG-WHtR等衍生指数，与代谢综合征、心血管疾病、NAFLD、糖尿病等结局做关联分析或预测模型。

常用数据库

  • NHANES
  • CHARLS
  • 中国健康与营养调查(CHNS)
  • MIMIC-IV

分析流程

  • 1.数据清洗 → 指数计算 → 基线特征描述 → 回归分析(Logistic/Cox) → RCS剂量反应 → 亚组分析 → 预测模型构建

核心套路

利用遗传变异作为工具变量推断暴露与结局的因果关系，经典两样本MR、双向MR、多变量MR、网络MR等方法，是目前最火的公共数据库发文范式。

常用数据库

  • IEU OpenGWAS
  • FinnGen
  • UK Biobank GWAS
  • GWAS Catalog
  • Open Targets Genetics

分析流程

  • 1.暴露GWAS数据获取 → 工具变量筛选(F<10剔除弱工具) → 两样本MR分析(IVW为主) → 敏感性分析(MR-Egger/加权中位数/留一法) → 异质性/多效性检验 → 共定位分析
